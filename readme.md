## 📝 Deskripsi

Website interaktif untuk memperingati Malam Nisfu Sya'ban 1446 H yang akan jatuh pada tanggal 14 Februari 2025. Website ini dirancang dengan tampilan modern dan animasi yang menarik untuk memberikan pengalaman spiritual yang mendalam bagi pengunjung.

## ✨ Fitur Utama

- 🕌 Desain Islamic yang elegan dengan tema biru malam
- ⏳ Countdown timer menuju Malam Nisfu Sya'ban
- 📿 Kumpulan doa dan amalan dengan tampilan interaktif
- 🎵 Background audio Sholawat dengan kontrol
- ✨ Efek visual particles dan animasi yang memukau
- 📱 Responsive design untuk semua ukuran layar
- 🌙 Loading screen dengan animasi
- 🕯️ Efek glass morphism modern
- 🌟 Parallax effect dan interactive elements

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3 (Advanced Animations & Effects)
- JavaScript (ES6+)
- Particles.js
- Google Fonts (Amiri)
- Responsive Design
- CSS Grid & Flexbox
- CSS Variables
- Modern CSS Features

```bash
# Clone repository

# Masuk ke direktori
cd nisfu-syaban

# Buka dengan live server atau browser
# Jika menggunakan VS Code, install Live Server extension dan klik "Go Live"
```
